# win_hdp_token_manager

This project aims to help users in Windows server to use spark, hdfs client with the native
hadoop delegation tokens.

## Project contents

This project has five submodules:
1. install-tokens.ps1: is the **one-time setup** script that configures a Windows PowerShell environment for secure Hadoop/YARN/Spark delegation-token management in multi-user (RDS) environments.
2. refresh-tokens.ps1: automates the retrieval, local storage, tracking, and revocation
    of Hadoop HDFS and YARN Resource Manager delegation tokens
3. token_convertor: A java class which converts a base64 encoded hadoop cluster delegation token into a binary file and stores it
in a specific file path.
4. pyspark_adapter: a python wrapper of pyspark to use the token generated by `refresh-token.ps1` to ensure user authentication.
5. sparklyr_adapter: an R wrapper of sparklyr to use the token generated by `refresh-token.ps1` to ensure user authentication.

## User global session token

Session Token: Acquire a fresh set of tokens every time a new console opens.
a global session token for all basic operations such as hdfs, yarn

## Spark job session token
For spark-submit, sparklyr and pyspark session, we need to generate a new token for each session, because hadoop 
will revoke the token after the job is finished. if we use the `user global session token` for spark-submit,
after the job is finished, we can not do hdfs or yarn command in the terminal anymore.
Because the `user global session token` is revoked during this process.
